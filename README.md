## 📌 Sobre o Projeto

**"Pesquisa de Atletas"** é uma aplicação web interativa desenvolvida durante a *Imersão Gemini*, com foco na manipulação de dados e construção de interfaces acessíveis e modernas usando DOM.

A proposta do projeto é permitir ao usuário **pesquisar atletas famosos** por nome, utilizando para obter informações relevantes, como:

- Biografia do atleta  
- Modalidade esportiva  
- Títulos ou premiações  
- Nacionalidade 

---

## 💻 Tecnologias Utilizadas

- **HTML5**  
- **CSS3 (responsivo e estilizado)**  
- **JavaScript (puro)**  
- **Vercel (Deploy)**  

---

## ✨ Funcionalidades

✔️ Interface moderna, limpa e responsiva  
✔️ Campo de busca para o nome do atleta  
✔️ Exibição dinâmica dos dados do atleta pesquisado  
✔️ Tratamento de erros e feedback ao usuário (ex: atleta não encontrado)  
✔️ Deploy otimizado e acessível em qualquer dispositivo
